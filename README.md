# Superstore Sales Analysis Project

## Problem Statement
The project aims to analyze Superstore sales data to understand sales performance, profit trends, customer behavior, and business growth opportunities.

## Tools Used
- Jupyter notebook for python
- MySQL

## Steps Performed
1. Imported the CSV dataset into Python
2. Performed data cleaning and preprocessing using Pandas
3. Conducted exploratory data analysis (EDA)
4. Prepared and processed the cleaned dataset for SQL analysis
5. Imported the dataset into SQL
6. Wrote analytical SQL queries for business insights
7. Identified trends, patterns, and performance metrics from the analysis

## Key Analysis Performed
- Sales and profit analysis
- Customer behavior analysis
- Product and category performance
- Regional sales analysis
- Discount impact analysis
- Trend and pattern identification

## Conclusion
Analyzed Superstore sales data using Python and SQL to identify sales trends, customer insights, profitability patterns, and business performance metrics through data analysis and analytical queries.
